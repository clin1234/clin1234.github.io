Advanced BLE characteristic settings

Defaults use the Nordic UART Service (NUS). Change these UUIDs to match your device's firmware, then scan again. This page does not support Bluetooth Classic SPP.

The page sends messages in 20-byte chunks for compatibility with small BLE MTUs. Actual BLE behavior depends on your peripheral's GATT implementation.

Requires a secure HTTPS page and a Web Bluetooth-capable browser for real BLE hardware. Chrome and Edge are recommended. The demo simulates device responses.
